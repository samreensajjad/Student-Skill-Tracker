# Student-Skill-Tracker
A beginner-friendly C++ console application designed to help students manage their skills and track their growth.
## About
Student Skill Tracker is a C++ application that helps students manage their skills and monitor their learning progress.

## Features
- Add new skills
- View saved skills
- Search for a skill
- Update skill levels
- Delete skills
- Track overall progress
- Save and load data using file handling
- Validate user input

## Technologies Used
- C++

## What I Learned
Through this project, I practiced C++ programming, object-oriented programming, functions, arrays, input validation, and file handling.

## How to Run
1. Download or clone this repository.
2. Open the C++ source file in Dev-C++ or another C++ IDE.
3. Compile and run the program.

## Project Status
Completed as a beginner-level C++ project.
